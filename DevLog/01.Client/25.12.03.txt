    [Resource][Editor][Tool] Common 타일맵 & 타일 스프라이트 업로드, 스프라이트 자동 확장 툴 도입

변경 요약
    타일 작업을 위한 타일맵 스프라이트가 DataServer/CDN 폴더에 대량 업로드 되었습니다.
    스프라이트를 정규화 하기 위해 에디터 툴을 만들었습니다.
    해당 툴은 특정 폴더를 스캔하여 32×32 기준으로 스프라이트를 자동 확장/패딩하고, 원본 파일 이름을 유지한 채 덮어쓰기 저장하도록 설계되었습니다.

상세 변경 내역
    1. Common 타일맵 리소스 업로드
        Stage1 구성에 필요한 타일 PNG 총 971개 이상이 Common 리소스 디렉토리에 업로드되었습니다.
        타입 구분 규칙(벽/바닥/데칼 등)에 따라 하위 폴더 구조 정리.
        스프라이트 Import 설정은 다음과 같이 일괄 적용:
        Pixels Per Unit = 32
        FilterMode = Point
        Compression = None
        SpriteMode = Default : Single
                     Atlas : Multiple (Slice 진행 예정)

2. 스프라이트 자동 정규화(Editor)
    서로 다른 크기로 제작된 스프라이트로 인해 발생했던 문제:
    일부 이미지가 잘려 보이는 현상
    타일 앵커(pivot)가 어긋나는 문제,
    타일맵에서 격자 정렬이 맞지 않아 타일 간 틈 발생
    
    이를 해결하기 위해 Unity Editor 전용 스크립트 SpriteNormalizer 도입.
    지정된 폴더(AssetNormalizeDirectory)의 모든 PNG 스캔
    스프라이트 크기 분석 후 32×32 타일 규격에 맞춰 상하좌우 패딩
    위치 오프셋은 자동 조정하며 앵커는 중앙(0.5, 0.5) 기준으로 통일
    결과물은 동일 파일명으로 저장하며, 원본은 외부 폴더에서 별도 보관하도록 가이드

3. 리소스 관리 전략
    원본 스프라이트는 아카이브 성격의 Backup 리포지토리로 이동
    게임에서 실제 사용하는 모든 타일은 “정규화된 버전”을 기준으로 사용
    추후 Addressables 전환 시, 동일 구조 유지하도록 설계 예정
