Commit 
    [Feat] SubSystem_ScrollSystem 구현

변경 요약
    패럴랙스, 오토 스크롤, 무한 스크롤을 개별 컴포넌트가 아닌 단일 ScrollSystem 서브시스템에서 일관되게 처리하도록 구조를 정립했습니다.
    ScrollAuthoring(인스펙터 데이터)와 ScrollRuntimeEntry(계산용 데이터)를 분리하여,
    카메라 기반 패럴랙스, 독립 Auto Scroll, 수평/수직/2D 무한 스크롤을 모두 조합 가능한 형태로 통합했습니다.
    Follow 효과(1,1), 패럴랙스 효과(0~1), 정적 레이어(None)를 명확히 구분할 수 있도록 단일 규약으로 재정의했습니다.

상세 수정 내용
    ScrollSystem.cs
        인스펙터 구성 규칙
            카메라를 따라가는 레이어
                ParallaxMode = Both, weightX = 1, weightY = 1
            패럴랙스 레이어
                ParallaxMode = Both, weightX/weightY 0~1
            독립 오토 스크롤 레이어
                ParallaxMode = None, useAutoScroll = true
            무한 스크롤 레이어
                ScrollMode 지정 (Horizontal/Vertical/Both)
            정적 데코레이션
                ParallaxMode = None, AutoScroll 사용 안 함, ScrollMode = None

        ParallaxMode( None / Horizontal / Vertical / Both )
            weightX / weightY 로 Follow·Parallax 강도 제어
        ScrollMode( None / Horizontal / Vertical / Both )
        AutoScroll 옵션(useAutoScroll / autoScrollSpeed) 
        
        ScrollRuntimeEntry
            Segment / Root / Size / AutoScrollSpeed / ScrollMode / ParallaxMode / WeightX·WeightY 필드 구성
            Follow가 없을 때 무한 스크롤의 기준점으로 사용할 CenterPos 필드 추가
        BuildRuntimeEntries / SetupAuthoring
            ScrollMode에 따라 1~4개 세그먼트 자동 생성
            PositionClone()에서 세그먼트 초기 배치
            RegisterRuntimeEntry()에서 CenterPos = root.position 저장

        UpdateScrolling
            Auto Scroll → Parallax → Infinity 처리 순서로 정리
                각 기능이 독립적으로 동작
            Parallax는 followDelta 기반으로만 동작
        
        ApplyParallax
            Weight(0~1)로 패럴랙스량 제어
            Horizontal / Vertical / Both 처리 분리
        
        ApplyInfinity
            width·height 기반 dx/dy 비교 후 ±size * 2 이동
            기준점(referencePos)
             · ParallaxMode ≠ None → follow.position 기반
             · ParallaxMode == None → CenterPos 기반

향후 작업 예정
    세그먼트 배열을 구조체 기반에서 Transform 레퍼런스 기반 풀링 구조로 이관
    Domain에서 스크롤 대상 오브젝트를 자동 로드하는 구조 추가
    Infinity Scroll의 세그먼트 운용을 풀링화하여 메모리 재사용 구조 정립
    ScrollSystem을 CameraManager와 연동하여 스테이지 기반 패럴랙스 계층 자동 구성 검토
