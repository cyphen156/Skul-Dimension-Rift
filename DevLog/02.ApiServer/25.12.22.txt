    [Refactor][Server][Meta] MetaIndex 재빌드 안정화 및 메타 스트리밍 적용

변경 요약
    Meta API 계약은 유지한 채,
    서버 구현을 운영 안정성 기준으로 리팩토링했습니다.

    MetaIndex는 런타임 재빌드를 고려하여
    임시 맵 생성 후 참조 교체 방식으로 동작하도록 수정되었습니다.

    Meta 응답은 문자열 파싱 대신, 
    파일 스트리밍 방식으로 제공하여
    불필요한 메모리 할당과 GC 부하를 제거했습니다.

상세 변경 내용

    1. MetaIndex 빌드 안정화
        - 기존 map.Clear() 제거
        - newMap 생성 후 참조 교체 방식 적용
        - schema 디렉터리 단위 순회로 탐색 범위 제한

    2. Meta API 응답 방식 개선
        - ReadAllText 기반 응답 제거
        - Results.File 기반 스트리밍 응답으로 전환
